# YT Music — модуль плеера для Mochy Music

Плеер в духе YouTube Music: большая обложка, текст песни у самого низа, строка прогресса с таймингами,
транспорты **shuffle · previous · play/pause · next · repeat**, красный акцент на истинно чёрном фоне.
Плюс страница **Quick picks** — лента поисков вместо домашних полок.

Текущая версия: **1.1** (идентификатор модуля `yt-music`, менять его нельзя — по нему Mochy понимает, что это обновление).

## Установка

### По ссылке на этот репозиторий (с обновлениями)

1. Опубликуй релиз: **Releases → Draft a new release**, тег `v1.1`, к релизу прикрепи файл
   `build/yt-music.mochyymodule.zip` (в имени обязательно `mochyymodule` и `.zip`), нажми **Publish release**.
   Черновик и pre-release Mochy не видит.
2. В Mochy: **Settings → Modules → add a module** и вставь ссылку на репозиторий,
   например `https://github.com/<твой-ник>/mochy-ytmusic`.
3. Mochy поставит модуль из последнего релиза. Новый релиз с тем же `id` = кнопка обновления на странице модуля.
4. Модуль появляется **выключенным** — включи его, и плеер сразу встанет первым в списке стилей.

### Файлом

`./build.sh` собирает `build/yt-music.mochyymodule.zip` → **add a module → from a file** → выбрать zip → включить.

### Ссылкой на манифест (без релиза, без обновлений)

`https://raw.githubusercontent.com/<твой-ник>/mochy-ytmusic/main/manifest.json` — картинки рядом с манифестом
Mochy тоже подтянет. Такой модуль не умеет обновляться сам, но поставить его можно сразу после `git push`.

## Сборка

Зависимостей нет, только perl (core-модули: `JSON::PP`, `Compress::Zlib`, `IO::Compress::Zip`).

```sh
./build.sh
```

Скрипт перерисовывает `icon.png` (512×512) и `banner.png` (1200×500) в `tools/art.pl`,
проверяет манифест по правилам парсеров Mochy в `tools/check.pl` и упаковывает zip в `tools/pack.pl`.

```
manifest.json     сам модуль: look, настройки, плеер, страницы, строки меню
icon.png          иконка    — рисуется tools/art.pl
banner.png        баннер    — рисуется tools/art.pl
tools/check.pl    проверка манифеста (блоки, условия, look-ключи, страницы, меню)
tools/art.pl      арт без графических библиотек
tools/pack.pl     упаковка zip: manifest.json в корне
build/            готовый архив (в git не попадает)
```

## Что внутри

- **Плеер.** Обложка с мягким свечением и пульсом по басу → ряд кнопок (лайк, текст, «настроить», •••) →
  название → исполнитель → строка прогресса с таймингами → транспорты → текст песни последним блоком.
  Шеврон слева, альбом мелким капсом справа в шапке.
- **Quick picks.** Своя строка в настройках и страница с полками: Quick picks, Mixed for you, Moods,
  Around the song (артист, live, каверы, инструментал), The look. Каждая полка открывает поиск в Mochy.
- **Меню ••• и шеврона.** Quick picks, «Open in YouTube Music», «Find live versions».
- **Настройки.** Тема (pure black / graphite), раскладка Home, вид Library/плейлистов, скругление обложек,
  пульс по басу, цвет прогресса. Выключил модуль — вернулись твои значения.

## Чего модуль не может

Home рисует само приложение, и у него три готовых макета (`MOCHYY`, `LISTEN_NOW`, `HOP_IN`); у Library/плейлистов —
три (`FLOW`, `CLASSIC`, `MINIMAL`). Модуль может только выбрать один из них, но не нарисовать новый Home или Library.
Страницы модуля показываются на его странице и в настройках, вставить их в Home нельзя — поэтому Quick picks живёт
отдельной страницей в один тап.

## Установка из каталога Mochy (по желанию)

В каталог попадают через PR с записью в `catalog.json` у Mochy: `{name, description, url, icon, adds, author}`,
где `url` — ссылка на этот репозиторий, `icon` — только https-ссылка, `adds` говорит, что модуль даёт
(`look` для этого: свой плеер и настройки).
